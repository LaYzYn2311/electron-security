Ιστορικό μετρήσεων

Επιδόσεις τώρα

Ποιες διεργασίες χρησιμοποιούν CPU/RAM αυτή τη στιγμή — ένα στιγμιότυπο, όχι συνεχής παρακολούθηση. Καθαρά τοπικά δεδομένα.

Πάτησε «Ανανέωση» για στιγμιότυπο.

Δίκτυο

Τοπικά στοιχεία δικτύου (καμία σύνδεση στο διαδίκτυο). Η δημόσια IP/τοποθεσία χρειάζεται ρητό κλικ παρακάτω.

🌐 Δημόσια IP & τοποθεσία (χρησιμοποιεί το διαδίκτυο)

Στέλνει ένα αίτημα στο ipapi.co για να μάθει τη δημόσια IP σου και μια χονδρική τοποθεσία (πόλη/χώρα/πάροχος). Τίποτα δεν στέλνεται μέχρι να πατήσεις το κουμπί.

🌍 Τοποθεσία εξερχόμενων συνδέσεων (χρησιμοποιεί το διαδίκτυο)

Στέλνει τις IP διευθύνσεις από τον τελευταίο έλεγχο ασφαλείας (μέχρι 10) στο ipapi.co για να βρει χώρα/πόλη/πάροχο. Χρειάζεται πρώτα έναν έλεγχο ασφαλείας.

🔓 Έλεγχος διαρροών email

Το HaveIBeenPwned πλέον απαιτεί πληρωμένο API key για αυτόματο έλεγχο — γι' αυτό αυτό το κουμπί απλά ανοίγει τον ιστότοπό τους στον browser σου, όπου μπορείς να το ελέγξεις μόνος/η σου. Δεν στέλνουμε το email σου πουθενά εμείς.
